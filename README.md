## Visualizar

Use um servidor estático na raiz para resolver os assets, por exemplo:

```console
python -m http.server 8000 --bind 127.0.0.1
```

Abra `http://127.0.0.1:8000/teste/index.html`. Imagens e bibliotecas por CDN dependem de internet.
